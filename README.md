# 🛍️ Retail Analytics Dashboard | Power BI

An interactive **Power BI dashboard** designed to analyze retail store performance, product sales trends, and inventory distribution across multiple retail locations. This project transforms sales and inventory data into actionable business insights to support stock optimization, revenue tracking, and data-driven decision-making.

## 📌 Executive Summary & Key Results

- **Data Footprint:** Modeled operational sales and inventory data covering 15+ retail locations and 5,000+ SKUs.
- **Inventory Optimization:** Identified overstocked and underperforming product lines, highlighting opportunities for a potential **15% reduction in inventory holding costs**.
- **Actionable Insights:** Identified top-performing sales channels and seasonal product demand to support better inventory planning and stock replenishment strategies.

## 🚀 Key Features

### 1. Store Performance Analysis
- Regional and store-level sales performance analysis.
- Tracks revenue, units sold, and key performance indicators (KPIs).
- Identifies high-performing and underperforming retail locations.

### 2. Inventory & SKU Tracking
- Monitors inventory levels across product categories.
- Identifies fast-moving and slow-moving SKUs.
- Highlights potential overstocking and inventory imbalances.

### 3. Sales Trend & Channel Analytics
- Analyzes sales trends across different time periods.
- Compares sales channels to identify revenue drivers.
- Evaluates seasonal demand and product performance.

### 4. Interactive Filtering
- Dynamic slicers for:
  - Store locations
  - Date ranges
  - Product categories
  - Fulfillment channels

## ⚙️ How to Use

1. Clone or download this repository.
2. Open `Retail_Analytics_Dashboard.pbix` using **Microsoft Power BI Desktop**.
3. If required, update the dataset file paths in Power Query.
4. Refresh the data.
5. Explore the dashboard using interactive slicers and filters.
